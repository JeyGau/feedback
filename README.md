# Beta tester feedback

Use the [issue tracker](https://github.com/JeyGau/feedback/issues/new/choose) to report bugs, suggest improvements, or share other feedback.

This repository and its issues are public. Do not include passwords, access tokens, private user data, or other sensitive information.

New submissions receive the `needs-triage` label. Review submissions before adding them to the product roadmap; accepted items can then be moved to **Wait for refinement** in the project board.
